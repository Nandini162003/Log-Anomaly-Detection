# Deep Learning-Based Anomaly Detection in HDFS Logs

##  Project Overview
This project processes large-scale system log data (250K+ records) to detect anomalies using deep learning techniques.

##  Technologies Used
- Python
- TensorFlow / Keras
- Pandas
- Scikit-Learn

##  Approach
- Log preprocessing and feature extraction
- Neural network model development
- Model evaluation using ROC-AUC, Precision-Recall, and F1-score

## Results
Achieved high classification performance with strong ROC-AUC and F1-score metrics.

##  Key Skills Demonstrated
Deep learning, classification modeling, anomaly detection, performance evaluation.
